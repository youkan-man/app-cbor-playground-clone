操作と探索ルール
全オフセット探索
0 から入力の末尾まで、1バイトずつ開始位置をずらし、各位置から1つのCBOR項目を解析します。Sequenceを有効にすると、エラーになるまで連続する項目の合計で評価します。途中の不正バイトは飛び越えません。
ヒット数は、正常に解析できたCBOR要素の数です。配列・マップ・タグ自身、キー、値、ネストした要素、文字列のチャンクを含みます。文字列内の各バイトは要素として数えません。
ヒット数 → 解析バイト数 → トップレベル要素数 → 小さいオフセットの順で選択します。探索候補をクリックすると、その位置の結果に切り替わり履歴にも保存されます。
探索は推定です。CBORは短い整数などが偶然一致しやすく、最多ヒットが実際の送信形式とは限りません。登録タグ固有の意味・妥当性までは検証しません。
右クリック
バイト：HEXのみ・Base64のコピー、選択部分の再解析。要素：値・表示値・パス・HEXのコピー、子要素展開、バイト文字列の中身を再解析。履歴：名前変更、固定、比較A/B、出力、削除。Shift+F10でもメニューを開けます。
履歴・比較
解析のたびに別の履歴を保存します。2件をチェックして比較。構造・値・エンコード差分、絶対バイト位置での比較、診断表記の並列表示に対応します。履歴はDockerの名前付きボリューム内のSQLiteに保存されます。
入力・出力
HEX / Base64 はバイナリを復号し、JSON / Diagnostic はCBORへエンコードして解析します。Diagnosticは基本表記（タグ、h'…'、b64'…'、simple、NaN/Infinity、不定長、数値幅）に対応。拡張表記の全機能やdCBORには対応していません。
JSON出力はバイト列・タグ・大整数などを $bytes / $tag / $integer / $map 等で表現します。元の型を保って再入力するにはDiagnosticを使用してください。JSON入力ではこれらは通常のキーとして扱います。
ショートカット
Ctrl / ⌘ + Enter：解析　Esc：メニューを閉じる　Shift+クリック：バイト範囲選択。境界線をドラッグするとペイン幅・高さを変更できます。
